# thomasbonar.github.io

Personal engineering portfolio of Thomas Bonar. Plain HTML, CSS, and JavaScript, with no build step, trackers, or outside services. 3D viewers use three.js (MIT), and fonts are Space Grotesk and JetBrains Mono (SIL OFL), all stored in this repository.

## Common edits
- **Add a headshot:** save a square-ish photo as `assets/img/headshot.webp`. It appears automatically in the About section.
- **Swap the resume:** replace `assets/docs/Thomas_Bonar_Resume.pdf` (keep the same file name).
- **Change text:** edit the `.html` files directly.
